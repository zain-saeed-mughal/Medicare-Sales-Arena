# Official Dark Maroon M asset

Source: user attachment `codex-clipboard-a085a9c8-133e-4e57-b746-683964602b51.png` (original file unchanged).

Published asset: `public/brand/medicare-maroon-m.png`, 578 × 466 RGBA PNG. Source crop origin: (399, 153). A traced alpha mask removes the textured surroundings and the openings between the strokes. No visible pixel was recolored or resynthesized: comparison found 145,844 opaque pixels identical to their source coordinates and 123,504 transparent pixels.

The image-editing tool was initially tried with the prompt: “Remove ONLY the dark textured background; preserve the exact original M silhouette, proportions, burgundy colors, gold fine edges, metallic bevels, highlights and dark dimensional sides.” Its generated result altered highlights and was rejected. The final asset uses original source pixels with a non-generative mask, per the user's explicit no-recreation requirement. Reproducible extraction: `.arena-qa/extract-brand.ps1`.

Consumers: shared Crest (Arena header / Admin sidebar / fallback branding previews), VelocityInsignia (champion stage and Admin dashboard), wheel hub, ceremony banner, and favicon. Functional trophy/medal/reward-category icons remain semantic icons rather than brand substitutes. Existing custom branding upload settings remain supported.

Visual evidence: `.arena-qa/official-logo-arena.png`, `official-logo-admin.png`, `gold-wheel-arena.png`, `gold-wheel-winner.png` (1920 × 1080 Chrome). Dashboard SVG-only size selector was corrected for the new image element.
